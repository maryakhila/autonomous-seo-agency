# SEO Agency Workflow

1. Project Manager distributes assignments.
2. SEO Research Specialist researches the market.
3. Keyword Analyst identifies target keywords.
4. Technical SEO Auditor checks website health.
5. SEO Content Writer prepares content.
6. On-Page SEO Specialist optimizes pages.
7. Competitor Analyst studies competitors.
8. Performance Analyst measures results.
